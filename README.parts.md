## نحوهٔ استفاده

در نوار ابزار روی «قطعه» بزنید و تب «قطعات صنعتی» را انتخاب کنید. سپس دسته و در صورت نیاز زیردسته را انتخاب کرده و با کادر جستجو نام فارسی/انگلیسی، سازنده، مرجع یا مشخصات را جستجو کنید. برای سبک ماندن WebView حداکثر ۶۰ نتیجه در هر نوبت رندر می‌شود و فایل JS دسته فقط زمان انتخاب همان دسته بارگذاری می‌شود. داده‌ها در `localStorage` قرار نمی‌گیرند.

با انتخاب رکورد، تعریف XML از primitiveهای قابل فهم برای `parseDef()` ساخته و از `addElement()` اصلی برنامه به صفحه اضافه می‌شود. فیلدهای designation، manufacturer، manufacturer_reference، supplier، quantity، unity و comment در مشخصات قطعه ثبت می‌شوند تا در پروژه و خروجی BOM همراه آن بمانند.

## هشدار درباره شماره‌مرجع و نمادها

شماره‌مرجع‌های `GEN-xx-xxxx` **شناسه‌های تولیدی داخلی این مجموعه** هستند، نه شماره سفارش واقعی یا تأییدشدهٔ کارخانه‌ها. نام سازنده در رکوردها برای نمونه‌سازی دسته‌بندی است و اصالت محصول یا شماره‌مرجع را اثبات نمی‌کند. قبل از خرید، طراحی اجرایی یا صدور BOM باید تمام موارد با کاتالوگ و دیتاشیت جاری سازنده تطبیق داده شوند.

نمادها شکل‌های عمومی و تولیدشده برای ویرایشگر هستند؛ آن‌ها نقشه‌های تأییدشدهٔ سازندگان یا گواهی IEC ندارند. برای نقشه‌های اجرایی باید توسط مهندس مسئول بررسی شوند. این مجموعه یک کاتالوگ پارامتری پایه است و جایگزین کاتالوگ تأییدشدهٔ سازندگان نیست.

## تولید مجدد و اعتبارسنجی

از ریشهٔ مخزن اجرا کنید:

```bash
python3 generate_parts.py
python3 validate_parts.py
```

اعتبارسنجی مجموع و تعداد هر دسته، یکتایی شناسه‌ها و زوج سازنده/مرجع، XML، primitiveهای مجاز، ترمینال‌ها، محدودهٔ مختصات و نحو JavaScript را کنترل می‌کند.
