# QET Mobile

ویرایشگر ساده‌ی **نقشه‌های برق روی اندروید** با پشتیبانی از فایل‌های `.qet` برنامه‌ی [QElectroTech](https://qelectrotech.org).

> این برنامه **پورت مستقیم QElectroTech نیست** (آن برنامه با Qt/KDE برای دسکتاپ نوشته شده). این یک اپ جدید و سبک است که فرمت `.qet` را می‌خواند و می‌نویسد.

## امکانات
- باز کردن فایل `.qet` (همه‌ی صفحه‌ها، قطعه‌ها، سیم‌ها و متن‌ها) و نمایش آن‌ها
- نقشه‌کشی: افزودن قطعه، کشیدن برای جابه‌جایی، چرخش، حذف، سیم‌کشی بین ترمینال‌ها، متن و برچسب
- کتابخانه‌ی قطعات: ۱۷ نماد آماده + قطعاتی که از فایل‌های `.qet` باز‌شده استخراج و ذخیره می‌شوند
- **وارد کردن کتابخانه‌ی دلخواه** (دکمه‌های «⬇ فایل» و «📁 پوشه» در پنجره‌ی قطعه، یا از منو): فایل `.qch`، `.zip` یا `.elmt` را انتخاب کنید، یا مستقیم پوشه‌ی `elements` را. نوع فایل از محتوایش تشخیص داده می‌شود و اگر قطعه‌ای نداشت، دلیلش گفته می‌شود. قطعات داخل حافظه‌ی برنامه ذخیره می‌شوند و با جستجو و فیلتر دسته قابل استفاده‌اند (هزاران قطعه هم کند نمی‌شود).
- ذخیره‌ی `.qet`، خروجی PNG، چند صفحه، بازگشت (Undo)، ذخیره‌ی خودکار، زوم با دو انگشت

## محدودیت‌ها
- تصاویر و شکل‌های آزاد (shapes/images) داخل فایل‌های `.qet` نمایش داده نمی‌شوند و در ذخیره‌سازی حفظ نمی‌شوند.
- مسیر سیم‌ها خودکار است (مسیرهای دستی QElectroTech حفظ نمی‌شود).
- قطعات `common://` که داخل فایل جاسازی نشده‌اند به‌صورت کادر قرمز نمایش داده می‌شوند.
- سازگاری کامل فایل ذخیره‌شده با QElectroTech دسکتاپ تضمین نشده است.

## ساخت APK با GitHub
1. این پوشه را در یک مخزن جدید گیت‌هاب بارگذاری کنید (شاخه‌ی `main`).
2. به تب **Actions** بروید؛ workflow با نام **Build APK** خودکار اجرا می‌شود (یا Run workflow را بزنید).
3. پس از پایان، از بخش **Artifacts** فایل `QETMobile-apk` را دانلود کنید.
4. برای انتشار در Releases یک تگ بزنید: `git tag v1.0 && git push origin v1.0`

نصب روی گوشی: فایل APK را باز کنید و «نصب از منابع ناشناس» را مجاز کنید.

## ساخت محلی
Android Studio (JDK 17) یا `gradle assembleDebug` (Gradle 8.7).

## مجوز
GPL-2.0 (مطابق QElectroTech). نمونه‌های داخل `examples/` از پروژه‌ی QElectroTech هستند.
