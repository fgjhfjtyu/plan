# QET Mobile 1.1

ویرایشگر سبک نقشه‌های برق برای Android با قابلیت خواندن و نوشتن فایل‌های پروژه‌ی `.qet` در قالب XML. این برنامه پورت مستقیم QElectroTech دسکتاپ نیست؛ یک ویرایشگر مستقل با پشتیبانی از بخشی از ساختار فایل‌های QET است.

## امکانات

- بازکردن، ویرایش و ذخیره پروژه‌های `.qet` و کار با چند صفحه
- افزودن قطعات آماده، سیم‌کشی بین ترمینال‌ها، متن، شکل و تصویر
- واردکردن کتابخانه از فایل‌های `.qch`، `.zip` و `.elmt` یا پوشه عناصر
- طراحی قطعه سفارشی ساده با خطوط، مستطیل، دایره، بیضی و ترمینال؛ ذخیره در کتابخانه محلی و خروجی فایل `.elmt`
- خروجی گرفتن تعریف قطعه انتخابی به `.elmt`
- Undo/Redo، ذخیره خودکار، جستجو و جایگزینی، کپی/چسباندن و ابزارهای تراز
- مدیریت صفحات، خروجی BOM و لیست سیم‌ها به CSV
- خروجی PNG، SVG، DXF و PDF؛ خروجی PDF فعلی مبتنی بر تصویر صفحه است
- زوم لمسی و شبکه نقطه‌ای
- اجرای آفلاین؛ رابط اصلی به CDN یا سرویس اینترنتی وابسته نیست

## طراحی قطعه سفارشی

از منوی برنامه «طراحی قطعه سفارشی» را انتخاب کنید. شکل‌ها را هرکدام در یک خط وارد کنید:

```text
line x1 y1 x2 y2
rect x y width height
circle x y diameter
ellipse x y width height
```

مختصات نسبت به مرکز قطعه هستند. ترمینال‌ها را در بخش جداگانه، هر خط به صورت `x y direction` وارد کنید؛ جهت‌ها: `0` شمال، `1` شرق، `2` جنوب و `3` غرب. پس از ساخت، تعریف قطعه در کتابخانه محلی ذخیره و یک فایل `.elmt` نیز صادر می‌شود.

## محدودیت‌های شناخته‌شده

- این پروژه جایگزین کامل QElectroTech دسکتاپ نیست و سازگاری صددرصدی همه ساختارها و نسخه‌های QET تضمین نمی‌شود.
- ویرایشگر قطعه سفارشی در این نسخه برای شکل‌های پایه است؛ ابزار گرافیکی آزاد و پشتیبانی از تمام primitiveهای QET ندارد.
- خروجی PDF رستری است؛ خروجی SVG و DXF نیز پوشش کامل همه انواع شکل‌ها و اجزای QET را تضمین نمی‌کند.
- لازم است خروجی‌های تولیدشده روی دستگاه Android و در QElectroTech دسکتاپ جداگانه آزمایش شوند.

## ساخت APK با GitHub Actions

1. محتوای این مخزن را در شاخه `main` قرار دهید.
2. از تب **Actions**، گردش‌کار **Build APK** را اجرا کنید.
3. پس از موفقیت، artifact با نام `QETMobile-apk` را دریافت کنید.

## ساخت محلی

Android Studio با JDK 17 و Gradle 8.7 موردنیاز است. دستور ساخت نسخه debug:

```bash
gradle assembleDebug
```

مجوز: GPL-2.0؛ برای جزئیات به فایل `LICENSE` مراجعه کنید.


## کتابخانهٔ ۹۰۰۰ قطعهٔ صنعتی

در پنل افزودن قطعه، تب «قطعات صنعتی» را باز کنید. کاتالوگ در ۱۲ دستهٔ جداگانه قرار دارد؛ دسته و زیردسته را انتخاب کنید یا با جستجوی فارسی/انگلیسی نام، سازنده، شماره‌مرجع و مشخصات را پیدا کنید. فهرست در هر نوبت حداکثر ۶۰ نتیجه نشان می‌دهد و فایل دادهٔ هر دسته فقط هنگام انتخاب آن بارگذاری می‌شود.

داده‌ها در `app/src/main/assets/parts/cat_01.js` تا `cat_12.js` هستند و برای ساخت مجدد/اعتبارسنجی از ریشهٔ مخزن اجرا کنید:

```bash
python3 generate_parts.py
python3 validate_parts.py
```

**هشدار:** کدهای مرجع با پیشوند `GEN-` شناسه‌های تولیدی داخلی‌اند و شماره سفارش واقعی سازندگان نیستند. مشخصات و نمادهای عمومی کاتالوگ پیش از استفاده در نقشهٔ اجرایی یا خرید باید با دیتاشیت رسمی و توسط مهندس مسئول بررسی شوند. جزئیات و تعدادها در `README.parts.md` آمده است.

## Android project integration

This delivery includes the Android application scaffold (`AndroidManifest.xml`, `MainActivity.java`, Gradle configuration, examples, and GitHub Actions workflow) together with the WebView editor and the 9,000-part industrial catalog. The Java bridge supports file open/save and local library import without relying on a missing native `Android.libIndex` implementation.
